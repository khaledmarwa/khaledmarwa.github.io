# معرض الأعمال

نماذج تطوير ويب — واجهات عربية (RTL)، متجاوبة، بدون مكتبات خارجية.

## المشاريع

| المشروع | الوصف | المعاينة |
|---|---|---|
| عيادة نبض | موقع تعريفي لعيادة أسنان + نظام حجز مواعيد | [`/clinic/`](./clinic/) |
| لوحة المخزون والمبيعات | لوحة تحكم إدارية: جداول، رسوم بيانية، تنبيهات، حفظ محلي | [`/inventory/`](./inventory/) |
| لوحة إدارة المشاريع | كانبان بالسحب والإفلات: أعمدة، بطاقات، تفاصيل، فلترة، حفظ محلي | [`/board/`](./board/) |

## التقنيات

HTML5 · CSS3 (Grid / Flexbox / Custom Properties) · JavaScript (ES6, بدون إطارات) · تصميم متجاوب · دعم الوضع الليلي

## النشر

كل مشروع صفحة مستقلة (`index.html`) — تعمل بفتحها مباشرة في المتصفح، أو عبر أي استضافة ثابتة (GitHub Pages / Netlify / Cloudflare Pages).
